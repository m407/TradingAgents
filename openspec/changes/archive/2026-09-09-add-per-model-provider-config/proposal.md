## Why

Модели `TRADINGAGENTS_DEEP_THINK_LLM` и `TRADINGAGENTS_QUICK_THINK_LLM` сейчас используют общий провайдер и URL, что мешает совместить OpenAI и Google через разные подключения. Кроме того, локальные проверки имён моделей молча удаляют явно заданный reasoning или подменяют его значение, делая конфигурацию ненадёжной для новых моделей и gateway (прокси-шлюзов).

## What Changes

- Добавить четыре необязательные настройки provider/URL для двух существующих моделей, доступные через Python-конфигурацию и ENV; новые значения по умолчанию равны `None`.
- Разрешать provider и URL независимо: индивидуальное непустое значение, иначе общее. Общий URL наследуется даже при другом индивидуальном провайдере; если оба URL отсутствуют, действует существующее поведение клиента.
- Выбирать reasoning-параметр и имя ограничения токенов по фактическому провайдеру каждой модели, сохраняя существующие значения моделей и назначения агентов.
- **BREAKING**: перестать удалять исходящий reasoning по имени модели и преобразовывать Google `minimal` в `low`. Явно заданные значения передаются без подмены; несовместимость может теперь приводить к явной ошибке SDK/сервера вместо тихого игнорирования.
- Передавать `reasoning_effort` также через существующие OpenAI-совместимые подключения и Azure, чей адаптер уже принимает этот параметр. Не добавлять новый протокол reasoning для Bedrock.
- Минимально адаптировать существующий CLI к индивидуальным подключениям, без новых меню; сохранить нормализацию ответов, DeepSeek round-trip и MiniMax separation.
- Обновить тесты и документацию. OpenCode используется только как образец, не читается приложением; новые реестры, aliases, зависимости и индивидуальные ключи авторизации не добавляются.

## Capabilities

### New Capabilities
- `per-model-provider-config`: индивидуальные provider/URL для deep/quick, независимое наследование и сохранение этих настроек в CLI.

### Modified Capabilities
- `per-tier-reasoning-effort`: разрешение по фактическому провайдеру каждой модели, передача без фильтрации по имени модели и без подмены значения, расширение на существующие OpenAI-совместимые адаптеры и Azure.

## Impact

- `tradingagents/default_config.py`, `tradingagents/graph/trading_graph.py`, `cli/main.py`: конфигурация, создание клиентов, выбор моделей и проверка ключей двух фактических провайдеров.
- `tradingagents/llm_clients/{openai,anthropic,google}_client.py`: удаление исходящих ограничений reasoning; существующие factory, registry и API-key mapping переиспользуются.
- Тесты ENV, графа, CLI, reasoning и локального формирования Google URL; `.env.example` и `README.md`.
- Изменяются требования основной capability `per-tier-reasoning-effort`, которые сейчас предписывают сохранять фильтры. Основная спецификация и архив не редактируются на этапе proposal; изменение фиксируется delta spec.
- Не меняются `.env`, конфигурация OpenCode, обработка содержимого ответов, checkpointing и распределение агентов. Сетевые обращения к реальным LLM не нужны для приёмки.
