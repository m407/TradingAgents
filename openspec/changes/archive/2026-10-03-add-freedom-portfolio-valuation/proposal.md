# Proposal

## Why

Текущий портфель Freedom Broker уже доступен через `tradernet-sdk` на `tradernet.global`, но его стоимость приходилось считать временными скриптами: поле `market_value` у RP-позиций не заполнено. Нужен отдельный повторно используемый Python-модуль, возвращающий проверяемую оценку каждой позиции и итоги по валютам, без смешивания RP-позиций с обычными акциями.

## What Changes

- Добавить отдельный Python-пакет `tradernet_global/` в корне репозитория, вне `tradingagents/`, с чтением текущего счёта через SDK и чистой функцией расчёта из переданных данных. Его код не зависит от TradingAgents.
- Возвращать типизированные оценки отдельных позиций с точными идентификаторами, количеством, валютой, источником цены, временем и статусом полноты.
- Добавить небольшой адаптер `tradingagents/freedom_portfolio.py` для явного преобразования результата в существующий `PortfolioContext`: сохранить состав владения, не подменять свободные деньги стоимостью активов или цену входа текущей ценой; многовалютный остаток передавать только при явном выборе одной валюты.
- Рассчитывать обычные акции и облигации по доступным котировкам, облигации — с номинальным коэффициентом и накопленным купонным доходом; RP/REPO/swap-позиции — по собственным ценам портфельного API.
- Возвращать отдельные итоги по каждой валюте с денежными остатками, без валютной конвертации. При недостатке данных показывать известную часть и явно отсутствующий полный итог, а не подменять неизвестное нулём.
- Ограничить транспорт выбранным доменом и командами чтения, защитить ключи и приватные данные от попадания в логи и ошибки.
- Добавить офлайн-тесты расчёта и транспорта, документацию публичного Python API. Не добавлять CLI, автоматическую передачу портфеля агентам, торговые операции или сохранение снимков.

## Capabilities

### New Capabilities

- `freedom-portfolio-valuation`: получение текущего портфеля Freedom Broker, оценка каждой позиции и отдельные итоги по валютам с явной полнотой и происхождением данных.

### Modified Capabilities

Нет. Существующие спецификации новостей и настроек моделей не меняются.

## Impact

- Новый пакет `tradernet_global/`, адаптер `tradingagents/freedom_portfolio.py`, отдельные тесты `tests/test_freedom_portfolio_valuation.py`, `tests/test_freedom_portfolio_fetch.py`, `tests/test_freedom_portfolio_context.py`, документация `docs/freedom-portfolio.md` и ссылка из `README.md`.
- Расширить package discovery в `pyproject.toml` на `tradernet_global*`, чтобы пакет присутствовал в установленном дистрибутиве, а не работал только из исходного дерева.
- Использовать уже установленную зависимость `tradernet-sdk>=2.2.0,<3`, существующие имена `TRADERNET_PUBLIC_KEY` / `TRADERNET_PRIVATE_KEY` и передачу окружения через fnox. Новые зависимости и изменения `fnox.toml` не нужны.
- Сохранить `tradingagents/portfolio.py`, его `PortfolioContext`, JSON-формат, checkpoint-подпись, граф агентов, CLI и новостной адаптер без изменений поведения.
- Сетевой доступ выполняется только при явном вызове функции чтения; импорт модуля и расчёт по переданным данным не требуют ключей или сети.
- Ранее проведённая живая проверка подтвердила `account_summary()` → `getPositionJson` и `get_quotes()` → `getStockQuotesJson` через API v3. Она не гарантирует доступность всех инструментов или атомарность снимка; реальные состав и суммы счёта не включаются в документацию и тестовые данные.
